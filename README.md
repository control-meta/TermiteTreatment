# TermiteTreatment

Responsive termite-control website built with Next.js, React, TypeScript, Lucide icons and custom CSS. It includes the homepage, Services overview, five service detail pages, About and Contact.

## Run the project

```sh
npm install
npm run dev
```

Open the address printed by Next.js. To preview on another device, use the computer's LAN address on the same network. Additional development hostnames belong in `allowedDevOrigins` in `next.config.mjs`.

```sh
npm run build
npm start
```

The current configuration creates a Next.js server build in `.next/`. `npm start` serves that build. `out/` is a separate static-export artifact and is not generated by the current configuration. The existing `.openai/hosting.json` is retained for the project's hosting workflow; it still targets a static export.

Check TypeScript without generating an incremental cache:

```sh
npm run typecheck -- --incremental false
```

## Project organization

| Path | Purpose |
| --- | --- |
| `app/` | Routes, layouts, global/responsive styles, metadata, robots and sitemap |
| `components/` | Shared header/footer, page sections, service picker, enquiry dialogs and contact controls |
| `lib/company.ts` | Company details, offices, service descriptions and image names |
| `lib/termiteScene.ts`, `lib/termiteMotion.ts` | Lazy-loaded Three.js termite scene and movement logic |
| `public/images/` | Optimized WebP images actually used by the website |
| `docs/` | Content research, image provenance, performance notes and cleanup reports |
| `ASSET-PROMPT.md` | Image-generation provenance and prompts |
| `next.config.mjs`, `tsconfig.json` | Framework and TypeScript configuration |
| `package.json`, `package-lock.json` | Commands and reproducible dependency versions |
| `.openai/` | Existing hosting configuration |

## Website behavior

- Mobile navigation includes expandable links to all five termite services.
- Review cards support automatic movement, arrow navigation and mobile swiping.
- Enquiry forms validate entries and open a review dialog. WhatsApp messages are only sent when the visitor chooses to send them.
- Botanical effects, scroll entrances and the Three.js scene support reduced-motion preferences.
- Company details and service content are maintained in `lib/company.ts`.

## Images and cleanup

The website uses 20 optimized WebP assets. Unused original PNGs and three superseded WebP images were removed during the 31 October 2026 cleanup. Historical prompt documents keep the generation record; their original-output paths are historical, not current runtime requirements.

`node_modules/` contains installed dependencies. `.next/` contains generated build/development output. They are ignored by Git. The old `.sites-checkout/` staging copy and stale static export were removed; the legacy staging source and history were first archived outside this project.
